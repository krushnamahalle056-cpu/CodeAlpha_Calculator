# Calculator

This is a simple calculator web application built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

The calculator performs basic mathematical operations through an easy-to-use interface.

## Features

- Addition, subtraction, multiplication, and division
- Clear and delete buttons
- Decimal number calculations
- Percentage and positive/negative sign support
- Keyboard support
- Responsive design for mobile and desktop
- Error handling for division by zero

## Technologies Used

- HTML5
- CSS3
- JavaScript
